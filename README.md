# Habit Tracker

A small habit tracker, built as a practice project — the real goals are learning
Supabase (auth + Postgres + RLS) and spec-driven development.

**Live:** https://growtopia8911-star.github.io/Habit-Tracker/
**Spec:** [SPEC.md](SPEC.md) — scope, data model, RLS policies, streak definition,
and the acceptance checklist. It is the source of truth.

Plain HTML/CSS/JS, no build step. Deploy is `git push` to `main`.
